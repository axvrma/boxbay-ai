# Source selection and access

The Port of Los Angeles publishes primary monthly loaded and empty import and export TEU. It is geographically coherent with the CAMX factor and has a long repeatable series. The 192 observations from 2010 through 2025 provide enough seasonal cycles for a two-year calibration and two-year holdout. These data describe port-wide activity. [Port of Los Angeles container statistics](https://portoflosangeles.org/business/statistics/container-statistics)

The captured tables came from official annual HTML pages using a browser-access research tool. Direct shell requests from the authoring host received HTTP 403. To refresh from a network with access run `python scripts/ingest_port.py`. To import saved copies run `python scripts/ingest_port.py --html-dir data/sources/import` with `2010.html` through `2025.html`. The training artifact records the input digest.

Kaggle screening considered Accenture's port-order competition and an anonymized logistics workbook. Published fields and known record counts are in the machine-readable source manifest. Raw coverage, completeness and license were not independently verified. Neither was used. An authorized reviewer can accept the competition terms and run `kaggle competitions download -c datathon-2022-upc-accenture -p data/sources/import`, then profile dates, port codes, row counts, duplicates, missingness, timing and redistribution rights locally. Promotion requires a documented mapping to facility boundary releases or pickup histories. [Accenture data page](https://www.kaggle.com/competitions/datathon-2022-upc-accenture/data)
